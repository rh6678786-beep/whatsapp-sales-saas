# Research: Features — WhatsApp AI Sales Agent

**Date:** 2026-05-30

## Feature Categories

### Table Stakes (must-have)

- Multi-tenant admin accounts with auth
- WhatsApp messaging (send/receive)
- Product catalog management
- AI-powered sales conversation
- Conversation history
- Lead qualification/scoring
- Order management

### Differentiators (competitive advantage)

- Multi-channel publishing (WhatsApp + Telegram + Facebook + Instagram in one platform)
- Smart price negotiation engine
- Multi-language AI (Urdu, English, Arabic, Hindi, Bengali)
- WhatsApp bot simulator for testing
- AI content generation for social media posts
- Re-engagement campaigns for inactive leads
- Payment screenshot verification workflow

### Anti-features (deliberately not building)

- Native mobile apps (web-first)
- Video generation (API limitation)
- Full CRM integration (staying focused on messaging)

## Current Implementation Status

All table stakes features are implemented. Most differentiators are implemented. The UI reorganization (Features tab) is the current active work.
